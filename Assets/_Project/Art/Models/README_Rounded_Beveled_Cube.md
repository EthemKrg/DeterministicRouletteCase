# Rounded Beveled Cube

- `Rounded_Beveled_Cube.obj`: Unity-friendly 1 unit cube with rounded bevels.
- `Rounded_Beveled_Cube_Low.obj`: lower-triangle Unity-friendly version of the same cube.
- `Rounded_Beveled_Cube_TopHalf_Low.obj`: top-half-only lower-triangle version for top-down use where the underside is not visible.
- `Rounded_Beveled_Cube.mtl`: warm off-white matte material reference for the OBJ.
- `Rounded_Beveled_Cube.glb`: portable glTF binary version with embedded PBR material.
- Bevel radius: `0.14`; bevel segments: `8`.
- Low-poly bevel segments: `4`.
- Pivot: centered at origin; scale: meters/Unity units; orientation: Y-up.
- Mesh density: `1944` vertices, `3468` triangles.
- Low-poly mesh density: `600` vertices, `972` triangles.
- Top-half low-poly mesh density: `371` vertices, `558` triangles.
